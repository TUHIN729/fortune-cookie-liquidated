One fortune-cookie line for a crypto trader who was just liquidated, written for the [Fortune Cookie for the Liquidated Trader](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c) bounty on make.fun. The market took the trader's money — but it left the cookie, and the cookie, unlike the wallet, is still full. Oracular setup, warm rueful twist, read in a single breath at 3am.

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`.
